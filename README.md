# REST API Book Management System

A production-quality REST API Book Management System built with Node.js and Express.js, featuring a premium Glassmorphism frontend UI.

This project was built to demonstrate full-stack development skills, REST API design, and modern UI/UX principles, using an in-memory data array (no database).

## ✨ Features
* Complete REST API for CRUD operations
* Modern Glassmorphism UI (Dark Mode)
* Real-time search & filter
* In-Memory Storage
* Request Validation & Toast Alerts

## 🚀 Quick Start
```bash
npm install
npm start
```
Open `http://localhost:3000` in your browser.
