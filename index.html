API Documentation

Full reference for all REST API endpoints

Base URL http://localhost:3000
GET /books Get All Books

Returns all books in the collection. Supports search and sort query parameters.

?search=Filter by title or author
?sort=titleSort by title A–Z
?sort=authorSort by author A–Z
Response 200
{ "success": true, "count": 5, "data": [...] }
GET /books/:id Get Book by ID

Returns a single book identified by its numeric ID.

Response 200
{ "success": true, "data": { "id": 1, "title": "...", "author": "..." } }
Response 404
{ "success": false, "message": "Book with ID 99 not found." }
POST /books Create a Book

Creates a new book. ID is auto-generated.

Request Body
{ "title": "1984", "author": "George Orwell" }
Response 201
{ "success": true, "message": "Book created successfully.", "data": {...} }
Response 400
{ "success": false, "message": "Validation failed", "errors": [...] }
PUT /books/:id Update a Book

Updates an existing book. Provide at least one field.

Request Body
{ "title": "New Title", "author": "New Author" }
Response 200
{ "success": true, "message": "Book updated successfully.", "data": {...} }
DELETE /books/:id Delete a Book

Permanently removes a book from the collection.

Response 200
{ "success": true, "message": "Book deleted successfully.", "data": {...} }
Response 404
{ "success": false, "message": "Book with ID 99 not found." }
INFO Status Codes HTTP Response Codes
200OK — Request successful
201Created — Resource created
400Bad Request — Validation error
404Not Found — Resource missing
500Server Error — Internal error
